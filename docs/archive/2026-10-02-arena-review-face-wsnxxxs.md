## 本轮目标

用户追问小红帽已有多件已验证作品、盲评大厅却显示「可盲评 0 件 / 0 个配置 / 作品不足」，要求调查全链路，并让 Gallery 审核与后台审核逻辑统一。

## 改动

- site/account.js：核验弹窗新增「通过核验后：在展览馆展示 / 进入正式盲评」；盲评未决定且生成方式合格（single-turn / none，文学题豁免）时默认勾选，随生成方式、人工介入实时启停；通过时显式发送 show_gallery、show_arena。「撤下」改为「全部撤下」两面。审核列表已验证作品标注「在盲评池 / 未进盲评」。批量核验增加「同时进入正式盲评」，发送 show_arena。审核说明文案同步。
- site/platform.js：已验证提示改为「已核验并优先展示；是否进入盲评以盲评开关为准」。
- site/arena.js：大厅未开放题区分「未进盲评池 / 配置不足」，空状态说明需管理员开启盲评。
- 配套后端 arenaofbias-server：batch-review 接受可选布尔 show_arena，admin.js 提示同步，admin.test 增加断言。

## 决策

- 保持后端分面审批（展览馆、竞技场分别决定），Gallery 审核补齐竞技场开关，而不是让 verified 自动进盲评。
- 盲评开关在作品合格且未决定过时默认勾选，管理员可取消。
