# 2026-11-26 · 浏览体验与性能复查 · wsnxxxs

- 负责人 wsnxxxs，执行 Codex。范围为正式与试运行分支的 Gallery 前端。

## 目标

复查前一轮缺陷，修复实际浏览中复现的阻塞、输入中断和移动端操作问题。

## 改动与决策

- 题库收到盲评统计时就地更新行动卡和变化的封面，保留搜索框、焦点、光标和筛选。目录或身份变更仍按原有路由逻辑更新。
- 搜索每次输入只解析一次查询，按当前目录和语言复用已折叠的题目信息与提示词。匹配顺序、提示词版本和命中摘录维持原规则。实时输入直接更新列表，避免每个字符触发重排动画。目录合并按题目一次分组作品，延迟图片观察器复用已知的近视口图片。
- 从总入口进入时，图片和字体共用 750 毫秒的准备预算。超时继续显示页面，单张图片解码失败可独立恢复。在线作品收到 iframe 载入事件后立即开始揭开遮罩。
- 窄屏作品筛选项在搜索下方自动换行。系统开启减少动效时，路由直接切换，省去视图转场。

## 验证

- 正式分支语法 122 个文件，162 项测试通过。试运行分支语法 135 个文件，210 项测试通过。合成数据包构建和严格收录检查均通过。
- Chromium 使用受控 API 和 200 道合成题目，在 320、390、1440 像素窗口比较修复前后的相同搜索输入。另复验 30 个路由场景，包括榜单、投稿与试运行站提示词弹窗。验证统计返回时的选区、封面更新、中英文搜索、手机筛选、返回题库、在线查看器和总入口的慢资源恢复。
- 两次验证均使用合成数据和本地 Chromium。生产后台、私有数据包与真机 Safari 未验证，本轮未部署。
