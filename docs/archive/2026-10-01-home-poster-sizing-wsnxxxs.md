# 2026-10-01 · 首页海报尺寸与模型取景 · wsnxxxs

- 负责人：wsnxxxs｜执行 AI：Codex。范围：Gallery 首页、共用模型预览及数据仓海报；未提交、未推送、未部署。

## 本轮目标

固定首页轮播和最近收录的卡片高度，适度统一海报视觉大小，修正 Boeing 等模型的过松取景；每件作品继续共用一张透明海报，题目和作品卡片淡入实时画面时位置一致。

## 改动

- `site/studio.css`：`.home-window-shot` 保持 16:10，使用相对定位、固定比例、`flex: none` 和溢出隐藏；图片绝对定位铺满，去掉海报 padding，以 CSS 变量缩放。此前首页动画、海报替换截图、提示词移到牌堆下方的未提交修改全部保留。
- `site/home.js`：海报加载后读取 `naturalWidth / naturalHeight`，计算 contain 面积 `min(r / 1.6, 1.6 / r)`，缩放为 `min(1.06, 1 / sqrt(area))`。已缓存图片立即计算，新发牌和最近收录都使用同一逻辑。
- `site/result-previews.js`：非建筑模型以静止相机投影中的实际可见网格顶点取景，排除隐藏对象、不可见或零透明度材质，遵守索引、drawRange、材质分组和实例矩阵。仅在场景创建时计算，后续帧复用投影范围。建筑仍沿用已有裁剪外框和底座。`readModel` 的原有 bounds 继续用于归一化，没有修改原作或模型包。
- 根因：Boeing 的世界轴外框本身接近模型跨度，但将该外框的八个角投到二维画面后，会把机身、机翼之间的空白一起纳入。只重新计算世界轴外框不能解决这个问题；实际网格投影同时改善海报和实时卡片。
- 数据仓保留 66 张重新烘焙海报：Boeing 18、机械键盘 19、铁路小镇 28、汽车 1。其余 55 张保留原文件，核对旧渲染器及新旧输出后刷新指纹。未新增缩略图或前端海报资源副本。

## 决策

- B 采用前端 load 事件读尺寸，没有新增 `previewPosterSize` 字段或请求。图片加载前使用 scale 1；容器高度始终固定，加载后最多放大 6%，不会发生布局跳动。
- 上限 1.06 小于烘焙相机的 1.08 留白，保留少量边缘空间。按 121 张海报的 alpha > 8 外框计算，应用首页 contain 和缩放后没有裁掉外框。不同模型的形状差异仍保留，面积仅做适度补偿。
- 海报仍按取景外框比例输出、长边 720px，没有改成固定比例画布。题目和作品卡片保持 contain，首页缩放仅作用于 `.home-window-shot`。
- 渲染器指纹是全局的。未受影响海报只在本轮核对后更新指纹，没有修改校验规则或增加绕过过期检查的开关。
- 提交需等待本轮用户确认；线上生效需发布新数据包、更新消费 pin，并发布匹配的前端。
