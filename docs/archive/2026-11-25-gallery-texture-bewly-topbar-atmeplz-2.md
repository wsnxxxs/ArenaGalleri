## 本轮目标

针对上一轮上线 `guided-trial` 后的实测细节反馈做第二轮打磨：
1. 修复 `#/team/<id>` 成员详情页顶部工牌挂绳（拉带）在旧顶栏底边高度处被截断的问题，使挂绳自然延伸至视口最顶边。
2. 在悬浮胶囊顶栏显示时，为其后方增加一层适度高度、与页面底色（`--bg`）一致、自上而下平滑渐隐的背景遮罩，保证滚过深色或高饱和内容时顶栏清晰舒服。
3. 全面改善手机端（`≤950px` / `≤760px` / `≤460px`）UI 适配体验。

## 改动

以下改动追加提交在分支 `feat/guided-bewly-topbar-texture`（PR #14）：

- 团队页挂绳顶部贯通（`site/platform.css`、`site/team.js`）：
  - `.team-stage` 由 `overflow: hidden` 改为 `overflow: visible; clip-path: inset(-140px 0 0 0)`，保持左右与底边严格裁切不溢出的同时放行顶部挂绳穿过透明顶栏；`renderLanyard` 锚点上移至 `ay = -108` 并按桌面/窄屏比例调整展开宽度，使双股挂绳与投影直达屏幕顶边且窄屏居中穿过左右胶囊之间。
- 顶栏同色向下渐变遮罩（`site/studio.css`、`site/app.js`）：
  - 为 `.topbar:not(.sandbar)::before` 增加自上而下由 `--bg` 平滑过渡至全透明的轻遮罩（桌面向下延伸 `22px`、手机 `16px`），随 `.is-topbar-hidden` 同步淡出上移；`#/team` 未滚动首屏略降遮罩浓度以保留顶部黑色挂绳清晰度；略微提高胶囊底色不透明度（浅色 `88%`、深色 `86%`）。
- 手机端 UI 适配精修（`site/studio.css`、`site/platform.css`、`site/app.js`）：
  - **顶栏与返回**：`≤950px` 隐藏船坞内 `GitHub` 外链避免首屏跳动；已登录态的头像与菜单钮合并为一枚双圆磨砂胶囊；修复直达平台题目页（如 `#/boeing-787`）时窄屏缺失「`< 返回`」的问题，并在 `≤460px` 有返回钮时自动收起站名文字防止拥挤。
  - **题库分类与首屏密度**：修复手机端点击一级分类（如「设计」）时二级子树在横向导航内纵向撑裂版面的问题，新增 `.side-mobile-subcats` 在窄屏以水平胶囊条展示二级细分；题库标题与「参与盲评」同行紧凑排布，三个筛选下拉框合为单行三列，隐藏领域与分类横滑滚动条，首屏即可完整露出两列题目卡片。
  - **排行榜与团队详情窄屏**：修复手机端排行榜工具栏三个下拉框被挤压为三个「全部」的问题（改为首行三等分完整显示「全部领域 / 全部 Harness / 全部服务商」）；`≤640px` 团队详情页将成员圆形头像与自我介绍改为左右并排呈现，首屏即可同屏看到工牌、头像与简介。
- 文档同步：更新 `docs/DESIGN.md` 与 `HANDOFF.md`。

## 决策

- `.team-stage` 采用 `clip-path: inset(-140px 0 0 0)` 而非整体上移舞台容器：既能让挂绳无截断通顶，又完全不改变 `< 返回`、右上角头衔、工牌单摆锚点与正交卡组的屏幕坐标。
- 顶栏遮罩直接复用 `color-mix(in srgb, var(--bg) ..., transparent)` 多段缓出曲线，深浅色主题切换时自动严丝合缝融入各自画布底色。
