## 改动

画廊浏览：

- 大厂新作品前置（`work-boost.js`）不再移动首张卡片。此前封面作品本身属于前置厂商时会被挪到同模型旧作品之后并折叠，失去「代表」位置；前置作品还会顶替或藏在本模型代表作之后。现在前置作品单独成卡，模型代表作保持原位。新增 `test/work-boost.test.mjs`。
- 首页没有超过 4 份带图答案的题目时，首屏计时器每 100ms 抛错、切换语言也抛错；之后目录补齐时首屏无法恢复。现在空首屏不计时，按钮常驻并隐藏，目录补齐后直接显示题目。
- 提示词里被引号、尖括号或英文标点包围的参考图文件名也能点开。
- 作品查看器的下拉选项在提示词版本已被移除时不再显示「· undefined」。题目页侧栏的模型数与标题统计一致。截图对照大图改用 `versionedMedia`，与缩略图共用 CDN 与缓存版本。
- 英文界面补「作者原始声明」「参考图 N / M」。修正 `app.js` 封面规则注释。

盲评、榜单与投稿：

- 访客在「开始盲评」提示里选择登录或注册后直接开始第一组，不再停在「登录状态已变化，请重新抽取」。
- 盲评结束时显示的「综合第 N 名」按综合榜实际显示的编号计算（隐藏不足 5 件作品的条目后连续编号，跟随读者的显示开关）。
- 精选榜为空时登录，空态按钮随身份刷新。引导试运行维度图在退出登录时丢弃在途读取，不再画出管理员数据。
- 上传作品时平台重连或会话刷新不再清空已填写的作品信息；未确认的试加载随重绘重新计时。
- 发起音乐题时「插入导出 MP3 要求」不再替换已插入的【参考图】段。
- 音乐投稿文案补英文（去掉打断整句翻译的 `<code>`），修正「捕获到 N 条」被通用模板误译。

平台与账号：

- 人机验证弹窗里的「登录」先关闭弹窗再打开登录框；此前登录框处于模态弹窗之外而无法操作。
- 后台目录省略 `site.emojis`（或 `site`）时，个人中心与审核列表不再崩溃，`efforts` 同样容错。
- 发送验证码时人机验证尚未完成，不再重置正在进行的验证；发送结果与垃圾邮件提示分两句翻译。
- 成员管理「在全部作品中查看」对含 `+`、`&`、`%` 的昵称正确带入搜索。成员等级、资格考试时长与上次成绩补英文。

构建与仓库：

- 展示目录的 `captures` 只保留题目条件，数据包里的其他键不再进入 `dist/data.json`；测试补私有键断言。
- 收录检查把 `terms`、`privacy`、`dimensions`、`team` 列为保留题目 ID。沙盘开始导入后清除 60 秒载入期限，慢导入不再被判超时后又重复摆放。
- `.gitignore` 增加取包中断时遗留的 `.datapack-download-*/`。`package-lock.json` 统一使用 npm 官方源地址（完整性哈希不变；配置镜像的环境由 npm 自动改写主机）。
- 文档：`ARCHITECTURE.md` 模块表把已删除的 `question-preview.js` 改为 `featured.js`；`README.md` 说明本地包仍需格式有效的 `datapack.json`；`PRODUCT.md` 更正跨题榜编号、封面回退和成员等级描述。

## 决策

- 媒体 CDN 对 API 绝对地址只替换源站、不拼接 base 路径，现有测试明确断言此行为，生产 base 也无路径，保持不变。
- 以下复查结论依赖私有数据或后台约定，本轮不改，列入下一步：海报固定路径、收录只检查 first / mobile 截图、联调冒烟不校验后台 pin、沙盘任务中无 `previewLoader` 的作品、综合榜分类名次（服务端 `standings`）与显示编号不一致。
