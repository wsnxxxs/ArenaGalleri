# 2026-11-26 · 历史作品、键盘操作与加载失败恢复 · wsnxxxs

负责人 wsnxxxs，执行 Codex。范围包括正式与试运行画廊的作品页、截图对照和按需加载的页面。试运行分支另含提示词弹窗。

## 目标与决策

让旧作品和重复投稿都能从题目页找到，让键盘用户完成展开、切换、查看大图和返回。两条发布分支分别提交修复，试运行功能继续在原分支验证。

## 改动

- 题目移除提示词版本后，对应作品保留独立卡片。同模型、档位和来源的同版本有多份投稿时，版本开关沿用目录中原先选中的第一份，其余投稿独立展示。封面标记仅随同一组的实际版本切换。
- 展开同模型作品时复用原来的按钮。切换作品版本后，焦点回到选中的版本。截图大图切换条件后，关闭会定位到对应缩略图，缺少该条件截图时会定位到大图当前显示的作品。
- 渲染作品列表时复用题目封面，并按作品 ID 查找所属折叠组。试运行提示词弹窗限制背景交互，Tab 和 Shift+Tab 在弹窗内循环，Escape 逐层关闭参考图和题面。后台统计触发同题重绘时保留打开入口。
- 页面、展厅及题目内嵌面板加载失败后立即显示错误和刷新操作。版本检查有三秒时限。确认页面版本过旧时仅更新提示文案，迟到的响应无法覆盖新页面。

## 验证

- 正式分支通过 122 个文件的语法检查和 164 项测试，试运行分支通过 135 个文件的语法检查和 212 项测试。两条分支的改动文件均通过静态检查。合成数据包构建成功，严格收录检查均为零错误、零警告。分别运行 npm start 后，首页与合成目录均返回 HTTP 200。
- Chromium 在相同的 16 个模型、96 件合成作品上比较修复前后。每次首次进入该题时，两个分支的题目封面计算都由 98 次降至 3 次。验证了历史版本、重复投稿、封面归属、按钮状态与焦点、两种动效设置、嵌套弹窗、版本查询超时和快速离开失败页面。英文界面的展开、收起与恢复提示也已核对。
- 在 390 和 1440 像素宽度回归 30 个路由场景。在 768 和 1024 像素宽度复查两条分支的题库、作品页及筛选区，页面无横向溢出。
- 浏览器使用受控接口和本地合成数据。生产后台、私有作品包和真机 Safari 尚待独立验证。
