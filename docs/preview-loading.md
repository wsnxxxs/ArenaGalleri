# 卡片模型预览

卡片直接消费私有包中的 `.sbox` 模型、WebP 海报和真实截图，不在前端仓库提交这些资源。可见卡片优先加载，正常模型读取不重新构建原作。

`preview-model.js` 读取压缩模型；`result-previews.js` 管理卡片渲染；`scene-resources.js` 回收场景资源。沙盘与回退加载按需导入对应模块。

海报指纹覆盖模型、场景配置和渲染实现。缺失或过期时本地构建提示并回退截图；发布环境设置 `CI=1` 后构建和收录检查失败。仅确认文件存在不能证明海报与当前模型匹配。

修改模型、预览渲染代码或相关 Three.js 版本后，在私有数据仓库生成对应海报并发布新包，再更新本地配置。原作在线运行文件、画质与交互不因卡片预览而改变。

平台注册投稿可通过后端提供 `previewModel`、`previewPoster` 和 `previewMode`，或独立展示图 `previewCapture`。这些媒体由后端保存，前端只读取；后端清单核对原入口、模型和海报的 SHA-256，源文件变化后旧适配不再进入 DTO。已经烘焙的跨源模型直接读取，不把跨源原作送进卡片提取器。投稿适配海报也须使用当前 Gallery 渲染器，取景与实时模型一致。

截图选择依次为独立展示图、桌面首屏、作者图库封面和其他截图（含手机）；卡片完整展示图片。题库封面保留管理员指定、票选、Opus 5.5 Max 和 Astra Max 的优先顺序；候选没有可用图片或模型时，选择其他有媒体的公开作品，质疑作品不参与。
