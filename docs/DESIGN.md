# 界面设计规范与风格

> 记录主站现有风格基线与工程约定。`site/studio.css` 是共用布局与视觉覆盖层，基础组件仍在 `style.css`、`platform.css`、`sandtable.css`、`exhibition.css`。

## 定调

像一间安静的深色展馆：墨色背景、细线分隔、左侧衬线标题与题目上下文，右侧紧凑的作品网格。作品卡片默认直接展示三维小模型，画布随卡片滚动。首页用动态标题、同题解答叠放卡组与提示词便签组织首屏，下方展示最近收录流动卡带；题库和平台功能沿用双栏布局。

大标题使用衬线；集合标题与作品名称使用无衬线。朱红用于选中导航、标签、主要按钮与焦点。默认深色，保留用户手动选择的浅色主题。

## Token

颜色只通过 `:root` 与 `:root[data-theme="dark"]` 的变量使用；`index.html` 的内联脚本在首帧前写入 `data-theme`。

| 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f5f4f0` | `#121211` | 页面底色 |
| `--surface` / `--surface-2` | `#fbfaf8` / `#eeede8` | `#191918` / `#222220` | 卡片与面板；悬停、分段控件底 |
| `--raised` | `#ffffff` | `#1e1e1c` | 按钮、对话框、菜单、对比栏 |
| `--ink` / `--ink-2` / `--muted` | `#1c1b19` / `#4a4843` / `#74716a` | `#ecebe6` / `#bcb9b1` / `#8d8a82` | 正文、次要文字、说明 |
| `--line` / `--line-2` | `#e3e1db` / `#d0cdc5` | `#2a2927` / `#3b3a36` | 分隔线、控件描边 |
| `--accent` / `--accent-soft` | `#bf3f28` / 9% | `#e46a50` / 13% | 唯一强调色 |
| `--inv` / `--inv-ink` | 墨底 / 纸字 | 纸底 / 墨字 | 反色组件与提示条 |
| `--img-bg` / `--mark-bg` | | | 图片占位、品牌标识底 |

布局覆盖：`--radius` 8px、`--radius-sm` 6px；对话框 10px、输入框 5px。`--wrap` 1728px、外框最大 1800px；`--gutter` 36px、`--sidebar` 300px、`--topbar` 65px。≤1200px 侧栏收为 265px，≤760px 常规顶栏由 59px 操作行与 32px 面包屑行组成（共 91px），沙盘顶栏 59px。阴影只用于浮层。

运行作品的舞台（在线预览、盲评、试加载）固定用 `#121211` 深底，不随主题变化，让作品自身的配色不受干扰。

## 字体

| 角色 | 字体变量 | 用在 |
| --- | --- | --- |
| 展示与标题 | `--serif`（宋体系） | 侧栏大标题、首页导语、步骤标题、对话框标题、盲评的 A / B 字母（斜体，窗格标题、载入层、手机切换器与投票按钮共用 `.ab` / `.pane-letter`） |
| 正文与界面 | `--sans`（系统无衬线） | 说明、表单、按钮、表格文字 |
| 数字与标注 | `--mono` | 统计数字、编号（No.01、01 / 02 / 03）、分数与区间、档位徽标、快捷键 |

侧栏标题 37px，题目卡片标题 18px；首页标题随窗口在 32–54px 间调整（手机27–36px），流动卡片标题 13px；右侧集合标题 20px，作品标题 16px。移动端侧栏 30px、作品标题 14px。数字使用 `tabular-nums`。

## 朱红的用法

用于 Logo 缺口、选中导航的淡底与文字、选中标签、主要操作按钮、焦点环、编号、「来源」徽标、选中对比描边、盲评中的「你的选择」、存疑与错误提示、必填星号、自己贴过的表情与待审核红点。普通次要按钮保持深色描边。

## 版式模式

- **首页海报**：牌堆与最近收录的图片窗口固定 16:10；按海报可见像素（alpha > 8）的外框等比缩放、居中，外框在窗口中占宽或高的 84%，四边至少留对应方向的 8%。不将海报内部透明空白重复计入留白，也不裁掉可见模型。首次加载前使用 84% 图片区域，加载后读取一次可见范围并缓存，同一作品仍共用一张海报。提示词在牌堆下方。
- **双栏外壳**：`.app-layout` 左侧 300px `.app-sidebar` 固定在顶栏下，可独立滚动；右侧 `.workspace` 随文档滚动。`pageStart` / `pageEnd` 为平台模块共用入口。
- **导航分工**：顶栏是全站导航，当前板块的入口用 `aria-current` 高亮（导航链接加淡底，头像加朱红描边与淡底）；侧栏只放本板块的视图（`sideNav` 生成的 `.section-nav`），不重复顶栏；子页面（题目、作品预览、展厅/沙盘、上传、盲评）在顶栏提供唯一的「返回 X」（`backLink`），普通页位于品牌后，预览与盲评对局位于左端。X 是读者来自的页面；直接打开或从下级返回时退回上级。窄屏只显示「返回」，完整目标保留在链接提示中。题库分类写入地址 `#/questions/<分类>`，浏览器后退、前进及返回上一历史条目时恢复原滚动位置。同一板块内切换视图时侧栏保持不变。
- **首页**：左侧衬线动态标题、说明和主入口，右侧最多五张浏览器窗口样式的解答卡片错位叠放，提示词便签叠在卡组边缘；题目标签与暂停轮播位于首屏底部。首屏下方为最近收录卡带与平台盲评入口。桌面卡片按窗口宽高有限缩放，内容至少撑满窗口；手机自然纵向排列。桌面首屏分隔线正中有滚动引导胶囊，滚动超过60px淡出，手机隐藏。
- **题库**：侧栏为一组导航：全部题目、各分类（图标与题数同排行榜）、细分隔线、模型索引；右侧搜索与题目卡片按工作区宽度换行，桌面每行最多三张，末行分配剩余宽度；≥1100px 时单卡最大半行宽，避免单条搜索结果被放大整行；手机保持两列。封面高度上限随视口在 180–280px 之间调整，手机上限 160px。每卡一张预览图、分类（朱红）与最多两个标签（灰）、发布者头像、标题、简述、日期与解答数量；标题行下方的筛选工具栏沿用题目页样式（左侧说明文字，右侧无标签文字的下拉框，选项自带名称与数量），模型索引同样有搜索与厂商下拉。内容较少时页脚仍在工作区底部。
- 平台可用时，题库首位以虚线卡片呈现「下一道题，由你来出」；静态档案不显示该卡片。
- **题库预览**：有解答的题目在平台可用时读取榜单，优先选榜首配置的已验证作品及其小模型；无榜单时优先该题 Astra Pro 作品，否则选择可用截图或其他作品。零作品题不请求榜单，显示「等待第一份答案」；有作品但无可用预览时显示「暂无预览图」。榜首没有小模型时保留作品截图。模型先显示同机位海报，画布就绪后淡入；桌面可随鼠标轻转，手机与减少动态效果偏好下不转动。布局、卡片比例与题目链接保持一致。
- **排行榜**：共用双栏外壳，侧栏视图为「综合」与数据包题目 `category` 各一项（文学、静态网页、建模，计数为题数）；标题行右侧是搜索模型；工具栏左侧是比较统计，右侧依次为题目下拉（仅题型视图，选项带作品数，作品不足的题禁用）、Harness、服务商与计分单位。服务商筛选为全部 / 官方 / 非官方 / 未注明。单题沿用 `#/leaderboard/<题目>`，侧栏停在所属题型。
- **作品页**：左侧题目信息与作品 / 截图 / 提示词 / 排行榜导航；右侧搜索、厂商 / Harness / 服务商下拉与排序、截图 / 小模型切换、作品网格。服务商筛选为全部 / 官方 / 非官方 / 未注明，选项带作品数。桌面三列，大屏四列，窄桌面与手机两列。
- **提示词与作品版本**：同题提示词面板用按钮切换长短原文，复制当前版本。同模型、档位、核验状态与来源的已标注版本结果合为一张卡，尚无作品的版本按钮禁用；并排预览两栏各自选择版本。作品计数保留实际份数，同时显示分组数。
- **分节**：`.collection-heading` / `.block-head` 无衬线标题、灰色计数、右侧操作，以细线划分内容。
- **目录式列表**：盲评题目、我的作品、审核、记录都用清单，不用卡片堆叠。盲评题目只保留每行底部细线，行标题为 16px 无衬线；其他清单保留各自既有样式。悬停只做底色和轻微缩进。
- **全屏舞台**：在线预览与盲评共用 `.viewer`：顶栏 56px、深色作品区、需要时右侧 344px 抽屉（窄屏为底部抽屉）。

## 组件

- **按钮** `.btn`：38px 高、1px 描边、6px 圆角；`.primary` 为朱红底；`.sm` 31px；`.ghost` 透明；`.danger` 朱红字；禁用降为 40% 不透明。
- **芯片** `.chips .chip`：5px 圆角、小号描边标签；选中为朱红字与淡底（`aria-pressed` 或 `aria-current`）。
- **分段控件** `.seg`：主题面板托盘，选中项用次级底色与朱红文字。用于截图条件、试加载尺寸、榜单单位、审核分类（位于「审核」标题右侧）。登录窗口不用分段控件：标题即当前模式，底部「还没有账号？注册 / 已有账号？登录」切换，注册规则写在输入框占位文字里。
- **徽标** `.badge`：等宽小字、4px 圆角；档位用默认样式，「暂定」用虚线。
- **状态徽标** `.status`：已验证实线（卡片中不显示，由分组表达）、未验证虚线灰字、存疑朱红描边。
- **表单**：标签在上、12px；输入框 40px、主题底色，聚焦时朱红描边；错误信息朱红 13px；确认项用 `.confirm` 描边块，未满足前置条件时半透明且不可点。
- **检查清单** `.checks`：每行「图标 + 粗体项名 + 说明」，底部细线；通过为墨色勾、提示为朱红圆点叹号、失败为朱红叉、等待为灰色时钟。
- **对话框** `dialog.sheet`：原生 `<dialog>`，10px 圆角、主题面板底、衬线标题、背景轻微模糊；审核面板为宽版两栏。
- **菜单** `.menu`：主题面板底、8px 圆角、阴影；窄屏导航菜单与未登录账户菜单在顶栏按钮下方展开；已登录头像直接进入个人中心。
- **提示条** `.toast`：底部居中的 6px 圆角提示条，3 秒后淡出。
- **平台提示条** `.platform-notice`：只在馆藏与平台服务版本不一致时出现在顶栏下方，整宽朱红淡底、细线分隔；朱红圆点 + 粗体「平台功能暂停」+ 说明，右侧「刷新页面」文字按钮，随页面滚走。平台页面自身已说明原因时不重复显示。
- **表情** `.reactions`：只显示有人贴过的表情（5px 圆角标签 + 等宽计数），末尾是无边框添加按钮；自己贴过的用朱红淡底。
- **榜单表格** `table.board`：顶部墨线；前三名名次用衬线，其余等宽；分数大号等宽、区间小字；区间横条是 4px 浅色细槽上的区间段与带底色描边的墨色圆点，最宽 260px，虚线标出 1000；区间段截取贯穿本榜刻度的「灰 → 朱红」渐变中自己所在的一段，越靠前越红；暂定为空心圆点。综合榜在厂商小字后列出各题型名次（「建模第 1」），不加新标记。
- **未收录模型**：注册表外的模型在厂商小字后加灰色「未收录」（如「Anthropic · 未收录」），悬停说明厂商来自投稿者填写还是按名称推断；推断不出厂商时只显示「未收录模型」，字母图标改为虚线。名称或别名与登记模型相同（忽略大小写、空格、-、_）的投稿直接显示为登记模型。

## 状态与平台页面的视觉口径

- **核验状态**：已验证作品不打标记，按组排在最前；未验证单独成组；存疑成组并默认折叠，封面灰度、标题降为次要色、写明原因，表情冻结。
- **投稿封面**：没有截图时显示「标题 + 截图生成中 / 暂无截图」的文字封面，底纹为极淡的斜线，不放占位插画。
- **盲评大厅**：沿用排行榜结构。侧栏为统计、「随机一道题」、未登录提示和题型视图（全部 / 文学 / 静态网页 / 建模，计数为可评题数）；右侧标题随视图变化，右上搜索题目，工具栏写可评与作品不足的题数。可评题目在前，「作品不足」按存疑分组的方式默认折叠；盲评规则与快捷键放在底部「盲评规则」折叠项，与「计分方法」同一组件。统一称「盲评」，「双盲」只用于说明文字。
- **盲评对战**：两侧只有斜体衬线字母 A / B 与「匿名作品」，载入层显示大号淡色字母而不使用封面（避免透露身份）；载入状态用小圆点表示（灰色载入中、墨色已就绪），不用文字胶囊。手机上匿名阶段不重复窗格标题行，「AI 生成」与重新载入并入 A / B 切换器一行。揭晓后身份淡入，朱红只标出「你的选择」：标题栏顶部一道 2px 朱红线 + 朱红淡底标签。投票条居中三个同样式按钮，快捷键以键帽样式标注。已评完或暂停时使用与榜单相同的虚线空状态。
- **发起题目**：共用双栏外壳；主表单按标题、简述、分类、标签、提示词、提交格式排列。分类为三张单选卡片（图标、名称、一句说明，选中为朱红描边淡底，≤760px 单列）；标签选填，用可移除芯片与已有标签建议；提交格式随分类变化，文学只显示固定格式。右侧为填写说明。
- **投稿**：三个编号步骤纵向排列，题目固定在侧栏；未解锁步骤半透明，试加载舞台按真实视口尺寸渲染后等比缩放。拖拽区下只留一行最常见的文件要求，其余收进「全部文件要求」；上传中拖拽区换成带「取消」的进度卡。作品信息只把必填项摆在外面，其余收进默认折叠的「补充信息」（编辑已有内容时展开）。服务商下拉必填，只选官方 / 非官方；Harness 只记名称，可手填并有相似名称提示，不再有版本。
- **阶段条** `.timeline`：投稿侧栏「提交之后」竖排，提交完成页横排（`.is-row`，最宽 720px）。已完成为实心墨点，当前阶段是唯一的朱红点与朱红标题，未到阶段文字转灰。投稿与发起题目共用 `stageTrack`。
- **个人中心**：侧栏为 概览 / 我的作品 / 我的题目 / 审核（管理员），审核也使用这一侧栏。概览资料区显示头像、20px 昵称与「编辑昵称」幽灵按钮、账号与加入时间，右侧「退出登录」为灰色文字按钮；编辑时换成输入框 +「保存」「取消」。近一年活跃图按周排成横向滚动的日格，用朱红由浅至深表示五档数量；表情统计展示六种表情及计数。我的作品 / 我的题目 / 审核各占一个视图，标题右侧放本视图的操作（上传作品、发起题目、审核分类）。清单行只有一个跳转入口（标题），右侧只放一个操作（删除或审核）。

## 动效

- 路由切换：`.page` 0.25s 透明度淡入，不移动卡片画布；图片解码后淡入。
- 浮层：菜单 0.18s、对话框 0.28s、提示条 0.3s，全部只用 `opacity` 与 `transform`。
- 悬停：按钮与链接只变色、箭头右移 2–3px；列表行底色渐变。
- 尊重 `prefers-reduced-motion`：全部动画与过渡降到 0.01ms。

## 响应式

布局断点 1200 / 950 / 760 / 460px，作品网格在 ≥1600px 四列。≤1200px 缩窄侧栏、投稿说明移到下方；≤950px 顶栏入口收进账号菜单；≤760px 侧栏变成文档顶部，题目导航和板块视图导航（`.section-nav`，含题库分类）横向滑动；≤460px 两列紧凑作品卡片。原预览舞台的 860px A / B 切换、640px 榜单列隐藏与表单断点继续保留。
