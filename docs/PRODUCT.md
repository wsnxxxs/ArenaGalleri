# Gallery 产品行为

首页组织同题解答卡组、提示词便签和最近收录。题目有两条轴：作答形式（存储值文学 / 静态网页 / 建模，界面显示为文本 / 网页 / 三维）决定提交格式和排行榜分组；所属领域（`domains`，每题 1–2 个，如数学、化学、建筑）只用于浏览。题库按形式、领域、关键词和模型筛选，形式与领域可以叠加并写进网址（`#/questions/<形式>/<领域>`，任一可省）。题目不设标签：题库与盲评大厅的搜索匹配标题、简述、形式、领域和全部版本的提示词原文，空格分隔的每个词都须出现，字母不分大小写并忽略空格、点、连字符和下划线（threejs 可找到 Three.js）。题库搜索时，标题、简述、形式或领域已包含全部词的题目排在前面，只在提示词里命中的排在后面，并在卡片上显示命中处前后的一小段提示词原文；各组内仍按所选排序。数据包与后台保留的旧 `tags` 字段不再展示，公开目录也不输出。领域词表优先取后台 bootstrap 的 `domains`，没有时用 `site/categories.js` 的默认表；数据中没有领域时侧栏不显示领域分组。排行榜在综合与各形式之外可再按领域收窄（`#/leaderboard/<领域>` 或 `#/leaderboard/<形式>/<领域>`），领域内少于 2 题或 50 次有效比较时提示样本不足；有效比较只数实际计分的比较；题目页支持作品搜索、来源筛选、模型预览、截图对照、在线运行和并排比较。

服务商只有官方 / 非官方，未填写显示「未注明」。官方指模型厂商自己的 API、网页或 App；聚合平台、云厂商、自部署等为非官方。题目页与排行榜按这三项筛选，旧平台 ID 或手填名称显示为非官方；排行榜仅计入两件作品的来源都符合筛选的比较。

题目、作品预览、展厅/沙盘、上传和盲评对局在顶栏提供统一的「返回 X」，返回读者进入时的页面；直接打开或从下级返回时退回上级。窄屏只显示「返回」。题库分类保留在网址中，浏览器后退、前进及返回上一历史条目时恢复原滚动位置。

完整提示词继续展示并支持复制。作品卡片和指南不提供私有源码、项目 README 或数据仓库跳转入口。必要的数据包协议标识保留在运行数据中。

题目页侧栏常驻「题面」（提示词原文，可切换长短版并复制），标题行右侧是「参与盲评」与「上传作品」。每个模型（不分推理档位）先展示一件代表作，同组其余作品折叠，模型名一行右侧的「+N 件」按钮可展开，展开的同组卡片左侧共用一条灰色边线；工具栏的「精选 / 同门」切换排列（记住读者的选择）：同门按厂商分行，每家作品按模型名称的系列与版本号（数字按数值比较，许多模型没有登记发布月份）、再按推理档位排开，换代处有箭头，只有一个模型的厂商合在末行「其他厂商」，存疑作品仍折叠在最后；同门不折叠、不放大封面作品，排序暂停使用；没有任何厂商出两个模型的题不显示这个切换；后台票选出的代表作带「代表作」标记；本题封面作品在至少三个已验证模型时排在最前并放大，盖「代表」印章并说明来历；筛选或搜索时列出全部匹配作品、恢复普通大小，数量显示为「X 个模型 · Y 件作品」。代表作与题库封面优先采用后台按盲评票选出的作品（`platform.featured`）；没有时，代表作按一轮且无人工介入、推理档位高、收录早排序，封面依次取 Claude Opus 5.5 Max、GPT-6 Astra Max，再没有则显示灰色占位。「体素山水 · 飞瀑穿云」封面固定使用 Gemini 4.x（灰度）High 的结果；该作品不可用时回退到通用规则。多轮或有人工介入的作品带「多轮」「人工介入」标签，只展示，不参与盲评；盲评大厅显示「可盲评 N 件」。选择逻辑见 `site/featured.js`。

同一道题的长短提示词通过按钮切换，复制使用当前版本。标明提示词版本的结果按相同模型、推理档位和来源合为一张卡片，按钮切换实际作品；并排预览中每一栏独立切换。每份作品保留自己的 ID，尚未收录的版本按钮禁用。

盲评与并排预览默认折叠作品的小型悬浮控件；至少一侧检测到控件时，顶栏显示「显示作品控件」，点击同时切换两侧，控件的 DOM 与交互状态保留。更换或重载一侧保留显隐选择，盲评换组与重新进入并排恢复默认隐藏。超过 6 个悬浮块或本次检测覆盖页面 40% 以上时沿用脚本的保护规则，不折叠这些元素。单栏浏览与新窗口保持作品原有控件。

账号、发起题目、投稿、核验、表情、盲评、榜单、个人中心和审核通过独立后台实现。前端不保存投票数据库或承担计分。没有可用后台时可继续静态浏览。

注册需先验证邮箱：发送验证码时完成人机验证，注册提交用户名、密码、邮箱与验证码。注册、账号绑定和找回密码发送成功后，提示未收到时检查垃圾邮件箱。旧账号仍可登录和浏览，发起题目、上传或贴表情前需绑定邮箱；未绑定邮箱的双盲选择不计票，界面提供绑定入口。个人中心可验证新邮箱后换绑。绑定状态只使用当前会话数据，旧接口缺省按已绑定处理。

投稿依次为选择文件、试加载、作品信息。多版本题目的投稿必须选择提示词版本，结果与馆藏一样进入同模型版本卡片。推理档位、服务商、生成方式与人工介入必填；生成方式仅一轮 / 多轮（只发一次提示词即为一轮，智能体自主迭代也算一轮），推理档位使用一个带常用候选的输入框，可选 Default、Low、Medium、High、XHigh、Max 或直接手填；空值不默认填 Default，不再另设「档位名称」；模型名称使用一个带已登记候选的输入框，优先选择已有模型，找不到时直接填写新名称；名称不匹配已登记模型时显示选填「模型厂商」，留空则按名称开头的系列词推断（同一系列对应多家厂商时不推断）；模型版本、生成日期和过程记录链接不再收集，补充说明仍为自由文本（`site/work-fields.js` 由投稿页、作者编辑与管理员审核共用）。投稿、作者编辑及管理员核验的服务商选项固定为官方 / 非官方（请选择占位不可提交），不提供手填名称；Harness 平铺选项，不按工具类型分组，沿用数据注册表的常用优先顺序，「其他（手动填写）」在末尾；已登记选项包含 WorkBuddy、MiniMax Code、Cherry Studio、Chatbox、Open WebUI、LibreChat、LM Studio、AnythingLLM、Continue、Kiro 与 Amp；只记录用的是哪一个（选项或手填名称），不再收集或显示版本。投稿页作品信息只把必填项摆在外面，简介、补充说明和封面收进「补充信息」；管理员内容审核与核验默认展开作品信息及补充信息，字段与投稿一致，可编辑提示词版本、模型（选项或手填）、推理档位、Harness、服务商、生成方式、人工介入、标题、简介与补充说明。核验清单已移除；两种审核弹窗都支持「只保存信息」，保存本身不作审核决定，只提交实际改动，旧缺项不自动填成 Default 或其他值。离开投稿页不丢弃草稿，24 小时内重新进入同一道题可以继续试加载。试加载 30 秒没有收到载入信号时，作者可在新窗口确认后继续。开启内容审核时，自动审核（6 Luna）通过后进入作品核验流程，公开展示以人工决定与展示开关为准；没能确定的转管理员人工复核，被拒的不公开并向作者显示原因。提交完成页用阶段条显示进度，并和「我的作品」一样每 15 秒刷新一次，最多 10 分钟；审核通过前作品标题链接到私有预览。后端报告自动审核不可用（`site.autoModeration === false`）时，文案改为由管理员检查内容。管理员审核页分为待处理（题目 / 内容 / 核验）和已处理（按全部 / 已公开 / 不进盲评 / 已撤下 / 存疑 / 已拒绝 / 机审拒绝 / 疑似注入筛选，筛选带数量；机审拒绝指非人工决定的拒绝，疑似注入指类别含提示词注入的拒绝）与记录，只有三个待处理标签显示人工待办数，自动审核中单独展示、不计数。馆藏不进入审核队列。内容审核可通过（理由选填）、拒绝（理由必填）或重新自动审核；内容与题目放行后进入当前面核验。新题示例可在题目卡片就地审核内容，所属题目被拒的示例归入已拒绝。核验先保存修改的信息，再提交决定；Gallery 单件与批量通过核验使用投稿表单的完整必填校验并开启展览馆，批量资料不完整的作品不发送决定、保持选中并显示缺项；只保存信息、内容决定和存疑允许保留已有缺项，存疑仍要求原因，撤下只关闭展览馆展示、保留核验状态。当前面没有核验记录时优先进入核验，不因原有展示开关开启而跳过；审核页载入后侧栏与菜单待办数使用当前三队列合计。决定后自动打开同一队列最早的下一件。核验通过后作者不能再编辑，是否进入盲评由管理员决定。

发起题目先填写题目信息（作答形式必选、所属领域必选 1–2 个，不再填写标签；提交格式跟随形式：文本固定为纯文本 / Markdown（.md 由后台排版，支持标题、列表、引用、代码、表格与 LaTeX 公式，含公式的页面由后台加载 KaTeX 显示；.txt 不解析），网页与三维可选纯 HTML 与 Vite；管理员通过题目时可修正形式与领域），然后可直接「提交题目」，也可选「附上示例结果（选填）」，用共用的上传步骤（`site/submit.js` 的 `uploadFlow`）附上一份用该提示词生成的结果再一起提交（依赖后端：无作品的 `POST /api/questions`，以及 `__new__` 草稿与带 `work` 的同一接口）。新题目一律由管理员人工审核，通过后才进入题库；附带的示例结果同时走内容审核，题目通过且内容放行后才进入作品核验。提交完成页的阶段条同时显示题目审核与示例结果审核的进度。提交后作者在「我的题目」看到等待人工审核 / 未通过及理由，通过前没有公开页面；未公开的题目可以连同示例结果撤回。管理员在「审核 · 题目」里先看待审题目（最早的在前），可预览示例结果后通过、拒绝（必须写理由）或删除；侧栏与菜单的待办数包含待审题目。后端没有题目审核接口时，这个标签页只显示提示，作品审核照常。

「我的作品」按审核中、等待核验、已验证、存疑 / 未通过筛选，并逐件显示内容审核、题目审核和核验阶段。上传按钮旁显示等待核验名额，以后端个人上限为准；满额时给出原因。未经人工决定的作品只向作者和管理员开放预览，不能把自动审核通过称为已公开。核验通过也不自动保证进入盲评。

管理员可批量审核题目、内容和核验，每件独立处理，失败项保持选中并显示理由。审核弹窗可就地修改作品文字和登记信息，也可只保存信息；管理员修改保留内容审核决定。题目可编辑标题、简述、形式、领域和提示词，已公开且有作品的提示词只读，保存不改变审核状态。

作品卡片优先使用数据包中的海报与模型。截图、模型和运行资源均来自私有数据包，前端不维护副本。原作运行内容与页面公开展示的信息可以被访客保存。

默认深色主题，手动选择保存在本机。沙盘和展厅沿用已有交互。读取超限时显示稍后刷新提示，不自动重试。
