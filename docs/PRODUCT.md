# Gallery 产品行为

首页组织同题解答卡组、提示词便签和最近收录。题库按分类（文学 / 静态网页 / 建模，与排行榜题型一致）、关键词和模型筛选，标签只作补充描述；题目页支持作品搜索、来源筛选、模型预览、截图对照、在线运行和并排比较。

服务商只有官方 / 非官方，未填写显示「未注明」。官方指模型厂商自己的 API、网页或 App；聚合平台、云厂商、自部署等为非官方。题目页与排行榜按这三项筛选，旧平台 ID 或手填名称显示为非官方；排行榜仅计入两件作品的来源都符合筛选的比较。

题目、作品预览、展厅/沙盘、上传和盲评对局在顶栏提供统一的「返回 X」，返回读者进入时的页面；直接打开或从下级返回时退回上级。窄屏只显示「返回」。题库分类保留在网址中，浏览器后退、前进及返回上一历史条目时恢复原滚动位置。

完整提示词继续展示并支持复制。作品卡片和指南不提供私有源码、项目 README 或数据仓库跳转入口。必要的数据包协议标识保留在运行数据中。

同一道题的长短提示词通过按钮切换，复制使用当前版本。标明提示词版本的结果按相同模型、推理档位和来源合为一张卡片，按钮切换实际作品；并排预览中每一栏独立切换。每份作品保留自己的 ID，尚未收录的版本按钮禁用。

账号、发起题目、投稿、核验、表情、盲评、榜单、个人中心和审核通过独立后台实现。前端不保存投票数据库或承担计分。没有可用后台时可继续静态浏览。

注册需先验证邮箱：发送验证码时完成人机验证，注册提交用户名、密码、邮箱与验证码。注册、账号绑定和找回密码发送成功后，提示未收到时检查垃圾邮件箱。旧账号仍可登录和浏览，发起题目、上传或贴表情前需绑定邮箱；未绑定邮箱的双盲选择不计票，界面提供绑定入口。个人中心可验证新邮箱后换绑。绑定状态只使用当前会话数据，旧接口缺省按已绑定处理。

投稿依次为选择文件、试加载、作品信息。多版本题目的投稿必须选择提示词版本，结果与馆藏一样进入同模型版本卡片。生成方式与人工介入必填；模型版本、生成日期和过程记录链接为结构化选填项，补充说明仍为自由文本（`site/work-fields.js` 由投稿页和编辑弹窗共用）。投稿、作者编辑及管理员核验的服务商选项固定为未注明 / 官方 / 非官方，不提供手填名称；Harness 保留原有选项、手填名称、相似名称提示和版本。离开投稿页不丢弃草稿，24 小时内重新进入同一道题可以继续试加载。开启内容审核时，提交完成页和「我的作品」会显示审核中 / 待人工复核 / 未通过及原因；审核通过前作品标题链接到私有预览。核验通过后作者不能再编辑，是否进入盲评由管理员决定。

发起题目先填写题目信息（分类必选、标签选填；提交格式跟随分类：文学固定为纯文本 / Markdown，静态网页与建模可选纯 HTML 与 Vite），然后可直接「提交题目」，也可选「附上示例结果（选填）」，用共用的上传步骤（`site/submit.js` 的 `uploadFlow`）附上一份用该提示词生成的结果再一起提交（依赖后端：无作品的 `POST /api/questions`，以及 `__new__` 草稿与带 `work` 的同一接口）。新题目一律由管理员人工审核；附带的示例结果照常走内容审核与核验。提交后作者在「我的题目」看到等待人工审核 / 未通过及理由，通过前没有公开页面；未公开的题目可以连同示例结果撤回。管理员在「审核 · 题目」里先看待审题目（最早的在前），可预览示例结果后通过、拒绝（必须写理由）或删除；侧栏与菜单的待办数包含待审题目。后端没有题目审核接口时，这个标签页只显示提示，作品审核照常。

作品卡片优先使用数据包中的海报与模型。截图、模型和运行资源均来自私有数据包，前端不维护副本。原作运行内容与页面公开展示的信息可以被访客保存。

默认深色主题，手动选择保存在本机。沙盘和展厅沿用已有交互。读取超限时显示稍后刷新提示，不自动重试。
