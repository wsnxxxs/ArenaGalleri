# 作品收录入口

收录、原作修改、提示词、模型注册、厂商标识来源、许可、真实截图、模型包和海报生成均在独立私有数据仓库完成。本仓库只消费已发布的包。

1. 在数据仓库完成原作构建、许可核对、桌面与手机截图、模型包和海报检查，再发布不可变数据包。
2. 通过私有渠道更新本地 `datapack.json`，后台使用同版本包。
3. 运行 `npm run check`、`npm test`、`CI=1 npm run build` 和 `CI=1 npm run check:intake`。
4. 目视检查受影响题目、提示词、作品入口及卡片预览，记录结果。

需要参考图的题目在数据包中保存一套标准文件（`references/<题目ID>/NN-名称.扩展名`），题目的 `references` 按交给模型的顺序列出，提示词写明张数与各张说明；作品目录中的副本不用于展示。

同题长短提示词在数据包中保留同一题目 ID，并以 `promptVariants` 保存各版本原文；实际作品通过 `promptVariant` 标注使用的版本，每份作品保持独立 ID。没有作品的版本只展示原文，不创建占位作品。待同模型的实际版本结果收录后，核对卡片分组、禁用按钮和并排预览两栏独立切换。

消费端完整性检查不能证明截图真实、许可审核完成或全部原作交互正确。只改主站无需重新生成全部作品资源；改动预览渲染代码时重新生成受影响海报。
