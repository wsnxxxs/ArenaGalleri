# 中式建筑沙盘

三维沙盘用于浏览中式建筑作品的布局与结构。它使用专用构建副本提取场景，并统一相机、展台和光照；作品原始构建页面不被修改，在线预览和原作展厅仍运行完整交付。

沙盘支持旋转、平移、缩放、聚焦和俯视。选择作品会写入链接，刷新后恢复。环境包含随主站主题变化的渐变天空、草地、远山和疏林；原作在光源旁绘制的太阳球体会在导入时排除。为减少绘制开销，沙盘使用固定光照，不运行昼夜变化和动态阴影；静止时暂停重绘。

## 场景处理

- 专用载入副本只构建待展示的场景，不运行原作的 GPU 渲染与阴影。
- 直接复制顶点与实例缓冲，避免将大型几何转换为 JSON；载入按短时间片执行，让出主线程。
- 相同材质先去重，再合并可兼容的静态不透明部件；保留几何、顶点颜色、纹理和实例化。
- 轴对齐且相互接触的不透明体素会剔除内部面；旋转部件和透明材质保留原几何。
- 拖动持续丢帧时降低像素密度，最低为 0.55；沙盘关闭多重采样抗锯齿，默认画布最多约 120 万像素。

大型、不透明且无纹理的网格可生成远景细节层级。简化时按位置与法线边界聚合顶点，平均小范围内的颜色，并保留发光及材质附加顶点属性。总览使用简化网格，聚焦后恢复完整几何；透明、带纹理或不适合简化的网格沿用原几何。

控制台会记录作品的绘制对象数，以及完整和远景网格的三角形数量。多件作品同时运行的帧率会受设备与并发负载影响，不用于单个模型性能评分。
